Falta conectar Firebase

Pega la configuración de tu proyecto para usar la base de datos compartida.
  1. Crea un proyecto en console.firebase.google.com.
  2. Activa Authentication → Correo/contraseña y crea Firestore Database.
  3. Agrega una app web y copia el firebaseConfig en public/firebase-config.js.
  4. Despliega las reglas con firebase deploy --only firestore:rules.
Los pasos completos están en el README.
